# Схемы EWB 5.12

Это расширение даёт MCP-инструменты и инструкции для схем Electronics Workbench
5.x `.ewb`. Перед работой со схемой прочитайте
`skills/ewb-schematics/SKILL.md`.

Основные правила:

- сначала прочитайте файл и используйте возвращённые индексы элементов и номера выводов;
- у земляных символов общее обозначение `"0"`, поэтому для земли предпочитайте индексы;
- после каждого изменения вызывайте `ewb_validate` и рисуйте SVG-превью;
- сохраняйте контейнер `.ewb` и формат `Project_5_1`;
- не запускайте и не автоматизируйте EWB;
- не перезаписывайте исходный файл пользователя без явной просьбы.
